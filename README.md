# PAD ARCHIVE STORAGE (PAS)

パズドラの編成リンクを、階層フォルダとタグで整理するスマートフォン対応Webアプリです。

## 主な機能
- フォルダ作成・名前変更・削除・多階層管理
- 編成リンクの登録・編集・削除
- タグ付けと、編成名・URL・タグによる検索
- JSONバックアップのダウンロードと復元
- 分割QRコードによるバックアップと復元
- PC・スマートフォン対応
- ライト／ダークモード切り替え（ライトモードが初期設定）

## データについて
編成データとテーマ設定はブラウザの localStorage に保存されます。サーバーには送信されません。JSONまたはQRで定期的にバックアップしてください。

## GitHub Pages
リポジトリのルートに index.html を配置し、Settings → Pages → Deploy from a branch → main / (root) を選択してください。
